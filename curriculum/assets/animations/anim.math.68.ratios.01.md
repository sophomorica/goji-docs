## Learning goal

After watching, the child understands: a ratio compares two quantities *in order*; the same relationship can be written 2:5, 2 to 5, or 2/5; equivalent ratios grow by multiplying *both* parts; the unit-rate row is the pair where one part is 1.

## Beats

| Time | Visual | On-screen text / narration |
|------|--------|----------------------------|
| 0–12s | Two barrels + five hardtack packs (simple icons); labels lock as a pair | "For every 2 barrels, 5 packs. That *relationship* is a ratio: 2 to 5" |
| 12–28s | Three cards flip: **2:5** · **2 to 5** · **2/5** — same pair highlighted | "Three ways to write the same ratio. Order matters — 5:2 is a different deal" |
| 28–48s | Table grows: 2\|5 → 4\|10 → 6\|15 → 8\|20; both columns multiply by 2, 3, 4 | "Same recipe, bigger batch. Multiply *both* parts by the same number — equivalent ratios" |
| 48–62s | Highlight unit-rate idea: divide to get **1\|2.5** (or integer example 3:12 → 1:4); "per one" tag | "Unit rate asks: how many for *one*? That's the row that unlocks 'how many for N?'" |
| 62–72s | Trap: table where only one column scales — marked "not equivalent" | "If only one side grows, the relationship broke" |
| Close | Goji seal stamps a clean 2:5 card; end card | "Keep the pair honest. Build the table!" |

## Must show / must not show

- **Must:** order matters; three notations; double-both scaling; unit rate as "per one"; non-example of broken table.
- **Avoid:** jumping straight to cross-multiply without tables; percent in this brief (later objective); implying a:b always reduces like a fraction before understanding order.
