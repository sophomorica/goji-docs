## Learning goal

After watching, the child understands: a push moves things **away**, a pull brings things **toward** you, a **stronger** push moves things farther, a push or pull can **change which way** something goes — and **nothing starts moving by itself**.

## Beats

| Time | Visual | On-screen text / narration |
|------|--------|----------------------------|
| 0–15s | Hand at left pushes a striped ball; ball rolls away right | "A PUSH moves things AWAY from you." |
| 15–30s | Hand at right pulls a wagon's handle; wagon rolls toward the hand | "A PULL brings things TOWARD you." |
| 30–45s | Same ball twice: gentle tap → short roll; strong push → long roll | "A gentle push moves it a little. A STRONG push moves it FAR!" |
| 45–60s | Rolling ball met by a hand from the other side; path bends back | "A push can CHANGE WHICH WAY it goes." |
| Close (60–85s) | Wagon alone, perfectly still ("Can it start by itself? …No.") — then a hand arrives and pushes it into motion; stamps NOT BY ITSELF → A PUSH MAKES IT GO! | "Nothing moves by itself. It waits for a push — or a pull." |

## Must show / must not show

- **Must:** the same object gentle vs strong (distance visibly different); a pull causing motion just as clearly as a push; a long still beat where the untouched wagon does NOT move before the hand arrives; only a hand/forearm as the force-giver.
- **Avoid (misconceptions, brand, clutter):** no faces or eyes on ball/wagon/swing (nothing non-living may look alive — guards the living.01 boundary); no object ever starting to move without a visible push or pull; no "pull is weaker than push" framing; no confetti; calm single-object scenes.
