## Learning goal

After watching, the child understands: objects can be described by **color**, **shape**, how they **feel**, and their relative **size and weight**; big is **not** always heavy; and when we sort, the **rule** decides the group — the same objects regroup when the rule changes.

## Beats

| Time | Visual | On-screen text / narration |
|------|--------|----------------------------|
| 0–15s | Red ball, blue sock, yellow star in a row; each pops gently in turn | "Words can tell COLOR. Red ball… blue sock… yellow star!" |
| 15–30s | Ball, square block, diamond kite; each pops in turn | "Words can tell SHAPE. Round… square… pointy!" |
| 30–45s | Spoon, rock, sock; each pops in turn | "Words can tell how it FEELS. Smooth… rough… soft!" |
| 45–62s | Seesaw: big balloon on one side, little rock on the other; plank tips DOWN on the rock side; stamp BIG IS NOT ALWAYS HEAVY | "Big or small, heavy or light. The big balloon is LIGHT — the little rock is HEAVY!" |
| Close (62–85s) | Ball + button + kite grouped by color (red pair vs kite), then the SAME three slide into size groups (ball + kite vs button); stamp THE RULE DECIDES! | "The RULE decides the group. Same toys — new groups!" |

## Must show / must not show

- **Must:** the seesaw visibly tipping toward the SMALL object; the same three objects physically regrouping when the rule changes (the button leaving the ball's group, the kite joining it); one property per beat, three objects max on screen.
- **Avoid (misconceptions, brand, clutter):** no faces or eyes on any object (nothing non-living may look alive); never show a big object outweighing a small one without contrast the other way; no group labeled by more than one property at once; no confetti; plain cream backgrounds.

## What happens next on Goji

Practice: in-package property detective (5 which-word rounds incl. balloon-vs-rock) then the double sort (by color, then the SAME objects by size). Then the 5-item check, then the real-spoons-and-socks parent sort + journal hand-off.

## Brand / motion notes

Calm, clear, skippable; Pi-friendly; Goji warm seal-red/cream chrome. `prefers-reduced-motion` collapses beats to stepped stills. No confetti cascades.
