# Grade band: K–2

**Focus for owned curriculum:** foundations — number sense, early fluency, phonics/fluency reading, habits on the Goji.

## Math (priority lean)

- Place value to 100  
- Add/subtract within 10–20  
- Early equal shares / halves  

**Tools:** math drills, flashcards, short animations, simple PDFs  

## Reading

- High-frequency words  
- Short text retell  
- Listening/read-aloud via parent-selected books if decoding is early  

**Tools:** reader, flashcards, journal, parent quiz  

## Typing / writing

- Light exposure; don’t block literacy on full keyboard mastery  
- Journal one sentence  

## Coding

- Optional / family-specific; not required for K–2 spine  

## Band notes

- Sessions short; animations ≤ 60–90s  
- Prefer one objective per lesson  
- Parent quiz language should be readable by adults helping at home
