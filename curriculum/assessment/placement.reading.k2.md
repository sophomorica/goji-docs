## Quiz items

1. Which word says /h/ /e/ /n/? → hen / hne / han / he (blending)
2. Which word is "log"? → log / lag / gol (reversal) / loge
3. Which word says "cape"? → cape / cap (missed silent-e) / cpe / capp
4. "kit" + silent e makes → kite / kitt / kit / keet
5. Which word is "said"? → said / sed / sayd / siad
6. Which word is "where"? → where / were (confusable) / wher / whre
7. (After passage) What happened FIRST? → fox saw grapes / fox gave up / fox said they're sour / fox jumped (order)
8. What happened at the END? → fox left saying they're sour / fox ate grapes / fox climbed the tree / fox asked for help
9. WHO wanted the grapes? → the fox / the crow (other-fable intrusion) / the farmer / the hen
10. WHERE were the grapes? → on a high vine / in a basket / underground / in the fox's den

**Read-aloud minute:** child reads the same mini-fable aloud; parent judges smooth / choppy / not-yet-decoding (maps fluency.01 to developing / struggling / not started — read-aloud never grants mastered on day one).

**Seeding:** per ASSESSMENT.md §3; distractor tags: blending, silent-e, sequence, text-vs-guess.
