## Quiz items (2 per skill; distractor = named misconception)

1. Which number shows this many? (14 dots) → 14 / 41 (reversal) / 13 (off-by-one) / 4 (digit-as-count)
2. What comes right after 16? → 17 / 15 / 61 / 20
3. 52 is __ tens and __ ones → 5 and 2 / 2 and 5 (swap) / 52 and 0 / 50 and 20
4. 3 tens and 8 ones makes → 38 / 83 (swap) / 311 / 30
5. Which is greater: 39 or 41? → 41 / 39 (big-ones-digit) / equal / can't tell
6. Which is less: 78 or 87? → 78 / 87 / equal / can't tell
7. Which circle is cut into halves? → 2 equal / 2 unequal (equal-parts miss) / 3 pieces / uncut
8. Which is MORE cookie: one half or one fourth? → half / fourth (more-pieces trap) / same / can't tell

**Micro-drills:** addition then subtraction, 5 problems each, range 0–10. Accuracy ≥ 4/5 → placed-mastered for that fluency skill; 3/5 → developing; ≤ 2/5 → struggling.

**Seeding:** per ASSESSMENT.md §3. Note on the evidence sheet: "from placement day."
