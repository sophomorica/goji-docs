## Summary

World Geography is the most **schedulable** course in the catalog: nine region standards with an identical four-bullet shape means one well-built unit template stamped nine times — a region a fortnight fills the year. It is also where the SOL skills standard first demands source credibility/propaganda/bias evaluation explicitly, making it the natural home for the planned sourcing method. Highest-value next steps:

1. **Region-unit template** (WG.3–11) — locate → features → culture → economy, each step a chain stage (research → notebooks table → parent quiz → journal comparison); author once, run nine times.
2. **Map-skills opener** (WG.1) — ride the treasure-island navigation/maps topics the anchor already carries; charts and mental maps before the region tour begins.
3. **Sourcing-method pilot** (Skills WG) — the compare-two-accounts + credibility checklist lesson; the skills standard here is its first explicit SOL home.
