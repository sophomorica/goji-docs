# Writing lessons (grammar/mechanics + compose strands)

One markdown file per lesson when written:

```
lesson.writing.<band>.<strand>.<nn>.md
```

Example: `lesson.writing.k2.grammar.01.md`

Use template: [`../../../assets/templates/lesson-plan.md`](../../../assets/templates/lesson-plan.md)

Grammar lives in the **writing pillar** (learn how to think) but serves reading too — practice sentences sample from the on-device book library where natural (catalog ids in [`../../reading/reading-lists.md`](../../reading/reading-lists.md)).
