## 1. Goal (one sentence)

After this lesson, the child can place integers on a number line, compare and order them, and explain absolute value as *distance from zero* — not as “drop the minus.”

## 2. Sequence (teach → practice → comprehension)

| Step | Pattern | Minutes | Activity | Goji tool | Media |
|------|---------|---------|----------|-----------|-------|
| 1 | Hook | 3 | Yukon cold: "Morning is −12°. Afternoon warms to 5°. Which is colder? How many degrees did it climb?" Let the child feel that "minus just means cold" is not enough — *how far* from zero matters | (off-device) | — |
| 2 | **Teach** | 4 | Watch: number line grows left of zero; −3 is three units left; \|−3\| and \|3\| both land on 3 as distance; order −5 < −1 < 0 < 2 | animation (parent device preview for now) | `anim.math.68.integers.01` |
| 3 | **Guided practice** | 6 | Parent names five integers (mix positive, negative, zero); child places them on a drawn line in journal. Then compare pairs: −8 vs −3, −1 vs 4, \|−7\| vs 5. Swap: child invents a Yukon temp pair, parent places | journal | — |
| 4 | **Practice** | 8 | Flashcard-style oral round (or paper deck): order three integers; name absolute value; "which is farther from zero?" Mental math only for *compare* items if helpful — no signed arithmetic yet | journal, mental math (compare only — partial) | — |
| 5 | **Comprehension** | 5 | Quiz incl. order trap and \|n\| as distance; journal: place −4, −1, 0, 3, 6 on a line and write "\|−4\| = ___ because ___" | parent quiz, journal | `quiz.math.68.integers.01` |

## 3. School Day mapping (how a parent would assign today)

- [ ] Task 1: Journal — independent practice: place −7, −2, 0, 4, 9 on a number line and write \|n\| for each
  - Checklist: Zero marked · All five placed · Each absolute value is a distance
- [ ] Task 2: Parent quiz — `quiz.math.68.integers.01`, pass ≥ 8/10
- [ ] Task 3: Journal — "Draw a number line. Place −4, −1, 0, 3, and 6. Then finish: \|−4\| = ___ because ___."
  - Checklist: Line with zero marked · All five numbers placed · Absolute-value sentence uses *distance* (not "drop the sign") · Numbers ordered left-to-right on the line

(When integer-mode drills ship — TOOLS.md §6D — add a compare/order drill task here.)

## 4. Checks

- **Formative:** on −8 vs −3, a child who picks −8 as "bigger" because 8 > 3 is still reading magnitude as whole numbers — go back to the line (farther left = less).
- **Summative:** quiz ≥ 8/10 with the order trap and one absolute-value distance item correct; journal line is correctly ordered.
- **If not yet:** physical line on the floor with tape (negative bedroom / positive kitchen); walk distances from a zero door; replay `anim.math.68.integers.01`; retry quiz next day. Do **not** start integer operations (`integers.02`) until compare + \|n\| pass.
