## Intent

Teach mathematical **principles** with Claude Design animations and short lessons, then **reps** in learning games/drills that already exist (times tables, mental math, ±÷, word problems, fractions). Parent assigns **module-scoped** goals, not only “15 minutes of math,” and eventually sees **math standing** vs grade skills (Virginia checklist).
