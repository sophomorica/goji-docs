## 1. Goal (one sentence)

After this lesson, the child can read a nonfiction/domain text with a question in hand and leave with structured notes — source, facts in their own words, and new questions — instead of a wall of copied text.

## 2. Sequence (teach → practice → comprehension)

| Step | Pattern | Minutes | Activity | Goji tool | Media |
|------|---------|---------|----------|-----------|-------|
| 1 | Hook (discussion) | 3 | Pick the topic together (or from the current science/history thread). Ask: "What do you actually want to know about it?" Write 2–3 real questions before any reading — reading without a question is browsing | (off-device) | — |
| 2 | **Teach** (first run only) | 5 | Set up the note page in notebooks, three sections: **Source** (what am I reading), **Found** (facts, own words, one per line), **Still asking** (new questions the text raised). Rule of the page: if you can't say it without looking, it's not a note yet | notebooks | — |
| 3 | **Practice** | 17 | Read on the topic in the research app with the questions beside you; fill the note page as you go. Copied sentences get flagged, not scolded: "close the text, now say it" — then write *that* | research, notebooks | — |
| 4 | **Comprehension** | 7 | Child walks the parent through the notes with the source closed: answers to the starting questions, one surprise, one "still asking." Parent checks: are the Found lines in the child's words, and does each answer trace to the source? | notebooks (review) | — |

## 3. School Day mapping (how a parent would assign today)

- [ ] Task 1: Research — topic reading session, ~15–20 min
- [ ] Task 2: Notebooks — note page (Source / Found / Still asking), ≥ 5 own-words facts
- [ ] Task 3: Parent review — closed-book walkthrough, sign-off

## 4. Checks

- **Formative:** during practice, spot-check one Found line: "close it — say it." Fluent restating = real note; re-reading to answer = copying.
- **Summative:** parent sign-off on the note page (own words, question-driven, source recorded) — per OBJECTIVES.md this objective is a manual check, no quiz.
- **If not yet:** wall-of-copy notes → shrink scope to ONE question and one paragraph, and do the close-it-and-say-it loop orally before writing anything. No new questions in "Still asking" → parent models one aloud ("the text says X — so what about Y?"); curiosity is taught by example here, not gated.

## 5. Tools

- **Uses existing:** research app (reading surface), notebooks (note page), parent review.
- **Blocked on new tool:** nothing for v1. **Kiwix (offline Wikipedia) is the future source** for this lesson — when it lands, only the Practice reading surface changes; the note method and checks stay identical. Noted so ingest/engineering doesn't trigger re-authoring.

## 6. Authoring notes

- Prereq: `obj.reading.35.info.01` (text features) — previewing headings/captions is assumed, not retaught.
- This is the **note-taking spine** for every later research task, and the direct prereq for `obj.reading.912.info.01` (argument analysis maps onto the same page: Found becomes evidence, Still asking becomes objections).
- Topic choice is deliberately open — ride whatever the child is currently curious about; the method is the objective, not the topic.
- Writing crossover: a completed note page is allowed to seed a journal write-up ("teach it back in a paragraph") but that's the writing pillar's task, assigned separately.
