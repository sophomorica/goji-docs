## 1. Goal (one sentence)

After this lesson (run as a routine across *Anne of Green Gables*), the child can keep a running summary whose entries connect — so the whole plot arc, not just the last chapter, stays in hand.

## 2. Sequence (teach → practice → comprehension)

| Step | Pattern | Minutes | Activity | Goji tool | Media |
|------|---------|---------|----------|-----------|-------|
| 1 | Hook (discussion, session 1 only) | 3 | "Tell me everything that's happened in the book so far." Watch it come out as either the last scene or a flood of everything. Name the problem: long books leak | (off-device) | — |
| 2 | **Teach** (session 1 only) | 5 | The 3-sentence chunk summary, taught once: 1) *What happened* (biggest event only), 2) *What changed* (for Anne), 3) *What it connects to* (an earlier entry — by chapter number). Set up a "Running summary — Anne" page in notebooks | notebooks | — |
| 3 | **Practice** (every session) | 15 | Read the day's chapter-chunk (2–3 chapters), then add one 3-sentence entry to the running summary. Sentence 3 must point backwards — an entry that connects to nothing gets one revision pass | reader (`anne-green-gables`), notebooks | — |
| 4 | **Comprehension** (every 3rd session + book end) | 7 | Read the whole running summary aloud top to bottom; parent asks one arc question ("When did Marilla start changing? Which entry shows it?"). At book end: child writes a 5-sentence whole-book summary using only the running summary, then journal: "What did Anne want at the start vs the end?" | notebooks, journal | — |

## 3. School Day mapping (how a parent would assign today)

- [ ] Task 1: Reading — `anne-green-gables`, 20 min (today's chapter-chunk)
- [ ] Task 2: Notebooks — one 3-sentence entry in "Running summary — Anne" (sentence 3 must reference an earlier entry)
- [ ] Task 3: Journal — "Every 3rd day: pick one arc question from your read-aloud review of Anne and answer it using your running-summary entries."
  - Checklist: The arc question you picked · Your answer in 2-3 sentences · Which running-summary entry (or entries) backs it up

## 4. Checks

- **Formative:** sentence 3 is the tell — "connects to nothing" or "connects to the immediately previous entry every time" both mean the child is summarizing chapters, not tracking an arc.
- **Summative:** parent sign-off on the complete running summary + the end-of-book 5-sentence summary built from it (per OBJECTIVES.md this objective is manual; quiz TBD).
- **If not yet:** entries too long (retelling everything) → cap at 3 sentences hard and practice "biggest event only" orally before writing. Arc questions miss → reread just the child's own entries (not the book) and hunt for the answer there; if the summary can't answer it, that's the lesson — revise the thin entries.
