# Subject: Reading

**Pillar:** yes — *access to information* (see [`../../VISION.md`](../../VISION.md) §2)  
**Device homes:** `reader`, `pdf`, Speed Reading path, `quotes`, flashcards (vocab), research/Kiwix path, future book-tied quizzes  
**Parent task types:** reading (book + minutes), PDF lesson, parent quiz, journal  
**Offline libraries:** **Project Gutenberg** classics (curate by grade) + **Kiwix/Wikipedia** for domain reading later

---

## Intent

Build a reading pathway: decode / fluency → vocabulary → comprehension, using **books already on the device** and catalogable PDFs, plus teaching animations for abstract skills (main idea, inference, text structure).

**Gutenberg is first-class:** classic lineup (e.g. Black Beauty, Treasure Island, Poe, …) mapped to grade/readability. **Audit what is already installed** before buying new content.

**Kiwix:** offline Wikipedia can augment lessons and feed comprehension material (history/science texts) once pillar skills allow curiosity domains.
